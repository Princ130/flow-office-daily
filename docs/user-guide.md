# Quick user guide

1. Open the GitHub Pages application.
2. Select the office `.xlsx` workbook, or create a new workbook.
3. On a new business day, check the suggested opening cash and coin values against the physical count.
4. Enter or confirm P1, P2 and P3 daily limits.
5. Record receipts, payouts and pocket expenses.
6. Save the workbook after each entry.
7. At day end, enter the physical closing count and close the day.
8. Back up the updated workbook to a separate drive.

**Important:** If the browser downloads a new workbook instead of saving the selected file directly, replace the previous workbook with the downloaded copy. Always use the latest copy.
